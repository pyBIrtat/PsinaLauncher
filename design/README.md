# Дизайн Psina Launcher

Макеты, по которым сделаны интерфейсы ПК-лаунчера и мобильного приложения.

## ПК (JavaFX, `D:\launcher`)

- `launcher-pc.html` — полный макет интерфейса ПК-лаунчера (сайдбар, карточки
  клиентов, версии, моды, сайты, серверы, настройки).
- `pc-clients.png` — как выглядит список клиентов в собранном лаунчере.
- `pc-mods.png` — поиск модов.
- `pc-sites.png` — страница сайтов.

Палитра ПК: фон `#0b0d0b`, панели `#141814` / `#1a201a`, линии `#232b23`,
акцент `#22c55e`, текст `#e6efe6`, приглушённый `#8fa08f`. Есть светлая тема
(`#f3f6f2` / `#ffffff` / `#1c231c`).

## Телефон (Android, `psina-mobile`)

- `mobile-v1.html` — первый вариант макета.
- `mobile-v2.html` — финальный вариант (по нему сделан интерфейс).
- `mobile-icon.png` — иконка приложения (золотистый ретривер в очках на блоке
  травы, надпись `PSINALAUNCHER`).

Палитра мобайла: `bg #050806`, `bg2 #09100C`, `bg3 #0D1611`,
`card #111C16`, `card2 #16241C`, `card3 #1D2E24`, `line2 #24382C`,
`text #EAF4EE`, `muted #8EA398`, `accent #22C55E`, `accent_light #4ADE80`,
`accent_dark #15803D`, `ink #052E16`, `warn #F5A524`, `danger #FF6B6B`,
`portable #B9A7FF`.

Шрифты в макетах — Manrope / Inter / JetBrains Mono. В Android-приложении
кастомные шрифты не подключены (используется системный), это единственное
расхождение с макетом.
